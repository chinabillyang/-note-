🔑 第28页核心：能级交错到底啥意思？

🔥 记住这句话：先填4s，但失电子先失4s！

📖 三个概念秒懂

概念 通俗解释 类比
能层(n) 电子住的"楼层" 1楼、2楼、3楼
能级(l) 楼层里的"房间类型" 单人间(s)、标准间(p)、套房(d)
轨道(m) 房间的"朝向位置" 朝东、朝西、朝南...

⚡ 能级分裂（同楼层内）

规律：同一楼层内，s < p < d < f
原因：s电子"钻"得近，离核近→能量低；f电子"钻"得远→能量高
记忆：房间等级越高，能量越高

🔀 能级交错（不同楼层）← 考试必考！

现象：4s轨道竟然比3d轨道能量低！所以电子先住4s，再住3d
原因：4s电子"钻穿能力"超强，能钻到离核很近的地方，受核吸引强→能量低
🎯 能级顺序（必须默写）：
1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p → 7s → 5f → 6d → 7p
📝 口诀：n加0.7l，越大能量越高
4s: 4+0.7×0=4.0 | 3d: 3+0.7×2=4.4 → 所以4s先填！

🧮 Slater规则（计算题必考）

📝 计算步骤

分组：(1s) (2s,2p) (3s,3p) (3d) (4s,4p) (4d) (4f)...
确定被屏蔽电子：你要算哪个电子的σ？
找屏蔽电子及权重：
• 同组其他电子：σ = 0.35（1s之间为0.30）
• n-1层电子：ns,np的σ=0.85，nd的σ=1.00
• n-2及更内层：全部σ=1.00
计算总σ和Z*：
σ = 各组屏蔽常数之和
Z* = 原子序数 - σ

📖 例题：碳原子(Z=6)的2p电子

C: 1s² 2s² 2p²
被屏蔽电子：2p²中的某个电子
屏蔽电子：
• 同组(2s,2p)其他：3个电子 × 0.35 = 1.05
• n-1层(1s)：2个电子 × 0.85 = 1.70
σ = 1.05 + 1.70 = 2.75
Z* = 6 - 2.75 = 3.25

🎨 四个量子数（必背！）

量子数 符号 取值 决定什么 类比
主量子数 n 1,2,3,4... 电子层、能量主要因素 楼层号
角量子数 l 0,1,2...n-1 亚层形状(s,p,d,f) 房间类型
磁量子数 m 0,±1...±l 轨道空间取向 房间朝向
自旋磁量子数 ms +1/2, -1/2 电子自旋方向 顺/逆时针
💡 推论：轨道总数 = n²，电子总数 = 2n²
例如n=3：3²=9个轨道，最多18个电子

📋 电子排布三大规则

1️⃣ 能量最低原理

电子优先占据能量低的轨道！
顺序：1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → ...

2️⃣ Pauli不相容原理

一个轨道最多2个电子，且必须自旋相反
所以每个轨道里最多是 ↑↓

3️⃣ Hund规则（洪特规则）

简并轨道（如3个p轨道）中：
• 电子先分别占据不同轨道
• 且自旋方向平行
正确：↑ ↑ ↑ | 错误：↑↓ ↑

⚠️ 必须记住的特例

半满/全满/全空 更稳定！
Cr(24): [Ar] 3d⁵ 4s¹ ❌不是3d⁴4s²
Cu(29): [Ar] 3d¹⁰ 4s¹ ❌不是3d⁹4s²
其他：Pd、Ag、Au、Pt等也是类似特例
🎶 口诀：铬铜不守常，半满全满最舒畅！

🗺️ 元素周期表 = 电子排布的地图

🔍 判断方法

写出价电子构型：nsˣ (n-1)dʸ 或 ns²npʸ
周期数 = n（最高电子层数）
主族序数 = ns + np 电子数
副族序数 = (n-1)d + ns 电子数

📖 例子：Fe (Z=26)

Fe: [Ar] 3d⁶ 4s²
周期数 = 4（第4周期）
副族序数 = 6+2 = 8（VIII族，特殊）
但失去电子时：先失4s²，再失3d

❓ 最后自测

问1：为什么4s轨道比3d轨道先填电子？
答：因为4s电子钻穿能力强，钻到离核近处，受核吸引强，能量降低，所以E(4s) < E(3d)
问2：Fe³⁺的电子失去顺序是什么？
答：先失4s²，再失3d¹，得到Fe³⁺: [Ar] 3d⁵
问3：Cr的电子排布式为什么是3d⁵4s¹？
答：因为3d半满(3d⁵)加上4s半满(4s¹)，整体能量更低，更加稳定！
